# 科三路线通 · 苏州科技城

面向科目三备考学员的**路线顺序记忆训练**网页应用。支持 **C1 手动挡 / C2 自动挡** 切换。

> **顺序题练「记忆」，专项题练「手法」——这两件事必须分开练。**
> 学员把路线背得滚瓜烂熟，一上车照样熄火。所以本应用把「整条线路的顺序」和「每个动作的手法」拆成两套独立的训练。

---

## 它解决什么问题

科目三难的不是「会不会开车」，而是**在正确的路段、按正确的顺序、做正确的动作**。

- 🧠 **记不住顺序** —— 练车时全靠教练喊「该超车了」，脑子里没有完整流程
- 🔀 **线路混着记** —— 苏州科技城有多条线路，越练越糊
- 💡 **灯光容易挂** —— 语音一响脑子空白，远近交替和雾灯双闪反应不过来
- 📱 **没有随时自测** —— 只能到驾校才能练，通勤排队的碎片时间全浪费

## 功能

| 模块 | 内容 |
| --- | --- |
| 🧩 **路线顺序训练** | 打乱一整条线路的项目，按记忆点选成正确顺序，提交后逐项对照 |
| 🎧 **情境判断** | 给出线路名 + 一句语音播报，问这条线路上接下来播报什么。干扰项取自**同一条线路的其他项**，逼你区分相邻路段 |
| ⚑ **难点专项** | 按车型分叉。C1 练油离配合、加减挡、四挡要求；C2 练踏板使用、车速控制、超车新规 |
| 💡 **灯光模拟** | 12 组标准夜间场景，抽 5 题判分，逐题给讲解 |
| ⇄ **跨线路混合** | 给一段连续项目，判断它属于哪条线。专治「练了 A 号线、考到 4 号线」 |
| ★ **整场模拟** | 随机抽一条线路，按真实顺序走完：灯光 30 分 → 顺序 40 分 → 情境 30 分，给总分 |
| ↻ **错题重练** | 练错的题会自动记进错题本，一键重练 —— **答对即从错题本移除**，答错留下次再来 |
| 🗺️ **项目速查** | 每条线路的完整序列，点任意一项展开看：口诀 / 播报文本 / 操作要点 / 扣分点 |
| 📊 **我的** | 练习次数、平均掌握度、每条线路掌握度进度条（取最好一次的成绩）、错题本与重练入口 |

播报文本支持**朗读**（用浏览器内置语音合成，零依赖；不支持的环境自动隐藏按钮）。

**车型切换**在首页第一屏。切换后线路项目数（**C1 16 项 / C2 15 项**）、项目清单、难点专项三处同步变化。

> C2 自动挡取消「加减挡位操作」——自动变速箱由电脑换挡，学员无需手动操作离合与挡位，因此为 15 项。

## 快速开始

**不需要安装任何东西，不需要起服务器。**

```bash
git clone git@github.com:tangzzz-fan/DriverCareer.git
cd DriverCareer/prototype
open index.html          # macOS
# 或直接双击 index.html
```

页面在手机浏览器里也能正常使用（自适应布局），进度存在 `localStorage`。

### 核心设计：项目定义只写一份

「掉头」的操作要点在 `data/items.js` 里写**一次**，四条线路通过 `id` 引用它：

```js
// data/routes.js
{ id: 'uturn', src: 'map' }     // 只写 id + 来源，不重复写文字
```

**改一次 → 四条线路的速查、顺序题、错题反馈全部同步更新。** 这是避免维护地狱的关键。

## 给内容维护者（教练）

### 推荐：用可视化编辑页

打开 `prototype/editor.html`（线上就是 `你的网址/editor.html`），**不需要看懂代码**：

- 四条线路切换，用 **↑ ↓** 调整项目先后、**✕** 删除、从官方 16 项池点选添加
- 给重复出现的项目填「区分标签」——比如 2 号线有两次右转弯，要分别标「第 1 次」「第 2 次」
- 逐项修改「来源」标记：**教练亲自确认过的项，请从「待校准」改成「图上标注」或「实测已核」**
- 顶部实时校验：项目数对不对、有没有重名项

改完点 **导出 routes.js**，把下载的文件覆盖到 `prototype/data/routes.js` 即可。

### 也可以直接手改 `data/routes.js`

熟悉之后直接编辑文件也行，找到那条线路，调换 `id` 的先后顺序：

```js
// 改之前
{ id: 'meet',  src: 'map' },
{ id: 'uturn', src: 'map' },

// 改之后（把掉头调到会车前面）
{ id: 'uturn', src: 'map' },
{ id: 'meet',  src: 'map' },
```

**三条规矩：**

1. **只改顺序和文字，绝对不要删掉 `id` 那一行** —— 删了页面会报错
2. 文字里要用引号时，请用中文「」而**不要用 `'` 或 `"`** —— 会破坏文件语法
3. **每次只改一条线路，改完立刻提交** —— 出问题时一眼能看出是哪次改动导致的

### 改完一定要自查

双击打开 `prototype/index.html`，看首页能不能正常列出 4 条线路；点进改过的那条，**核对项目数**（C1 应为 16 项、C2 应为 15 项）。数字不对就是改漏或改重了。

## 开发与测试

改完代码或数据，跑一遍回归：

```bash
bash tests/run.sh          # 需要 node，无第三方依赖
```

测试用桩 DOM 直接执行 `index.html` 里的内联脚本，覆盖数据引用完整性、题型生成、判分边界、持久化与降级。**改数据后必跑**——线路节点引用错一个 id，测试会立刻指出来。

`prototype/` 整站零外部依赖（0 个 `script src` / `link href`），可直接双击 `index.html` 打开。测试从 HTML 里读内联脚本，因此**不需要构建步骤**。

## ⚠️ 数据核实状态

**数据是可追溯的，不是编出来的。** 每个节点带 `source` 标记，速查页用圆点可视化：

| 标记 | 含义 |
| --- | --- |
| ⚪ `std` | 国家统一必考项（起止固定） |
| 🟢 `pub` | **公开实测攻略已核实**（目前仅 2 号线） |
| 🔵 `map` | 路线图上明确标注 |
| 🟠 `inf` | 依路线结构推导，**待教练校准** |

考核项依据 **《机动车驾驶证申领和使用规定》（公安部令第 162 号）第三十四条**：C1 手动挡 16 项、C2 自动挡 15 项。**考场之间的差别不在于「考几项」，而在于这些项排成什么顺序、在哪个路段做。**

**目前 2 号线是唯一有公开实测全程记录的线路**（16 步完整可查）；其余线路中标记 🟠 的「路口右转弯 / 路口左转弯 / 通过人行横道线」三项位置为推导，**需教练确认后再定稿**。
