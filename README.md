# 科三路线通 · 苏州科技城

面向科目三备考学员的**路线顺序记忆训练**网页应用。支持 **C1 手动挡 / C2 自动挡** 切换。

> **顺序题练「记忆」，专项题练「手法」——这两件事必须分开练。**
> 学员把路线背得滚瓜烂熟，一上车照样熄火。所以本应用把「整条线路的顺序」和「每个动作的手法」拆成两套独立的训练。

---

## 它解决什么问题

科目三难的不是「会不会开车」，而是**在正确的路段、按正确的顺序、做正确的动作**。

- 🧠 **记不住顺序** —— 练车时全靠教练喊「该超车了」，脑子里没有完整流程
- 🔀 **线路混着记** —— 苏州科技城有多条线路，越练越糊
- 💡 **灯光容易挂** —— 语音一响脑子空白，远近交替和雾灯双闪反应不过来
- 📱 **没有随时自测** —— 只能到驾校才能练，通勤排队的碎片时间全浪费

## 功能

| 模块 | 内容 |
| --- | --- |
| 🧩 **路线顺序训练** | 打乱一整条线路的项目，按记忆点选成正确顺序，提交后逐项对照 |
| ⚑ **难点专项** | 按车型分叉。C1 练油离配合、加减挡、四挡要求；C2 练踏板使用、车速控制、超车新规 |
| 💡 **灯光模拟** | 12 组标准夜间场景，抽 5 题判分，逐题给讲解 |
| 🗺️ **项目速查** | 每条线路的完整序列，点任意一项展开看：口诀 / 播报文本 / 操作要点 / 扣分点 |
| 📊 **错题本** | 排错的项目和选错的题自动记录，存在本机 |

**车型切换**在首页第一屏。切换后线路项目数（**C1 16 项 / C2 15 项**）、项目清单、难点专项三处同步变化。

> C2 自动挡取消「加减挡位操作」——自动变速箱由电脑换挡，学员无需手动操作离合与挡位，因此为 15 项。

## 快速开始

**不需要安装任何东西，不需要起服务器。**

```bash
git clone git@github.com:tangzzz-fan/DriverCareer.git
cd DriverCareer/prototype
open index.html          # macOS
# 或直接双击 index.html
```

页面在手机浏览器里也能正常使用（自适应布局），进度存在 `localStorage`。

### 核心设计：项目定义只写一份

「掉头」的操作要点在 `data/items.js` 里写**一次**，四条线路通过 `id` 引用它：

```js
// data/routes.js
{ id: 'uturn', src: 'map' }     // 只写 id + 来源，不重复写文字
```

**改一次 → 四条线路的速查、顺序题、错题反馈全部同步更新。** 这是避免维护地狱的关键。

## 给内容维护者（教练）

改内容**不需要懂编程**，只需要改 `data/` 目录下的文件，往里面填数据。

**最常用的一件事：调整某条线路的项目顺序。**
打开 `data/routes.js`，找到那条线路，把 `id` 的先后顺序调换即可：

```js
// 改之前
{ id: 'meet',  src: 'map' },
{ id: 'uturn', src: 'map' },

// 改之后（把掉头调到会车前面）
{ id: 'uturn', src: 'map' },
{ id: 'meet',  src: 'map' },
```

**三条规矩：**

1. **只改顺序和文字，绝对不要删掉 `id` 那一行** —— 删了页面会报错
2. 文字里要用引号时，请用中文「」而**不要用 `'` 或 `"`** —— 会破坏文件语法
3. **每次只改一条线路，改完立刻提交** —— 出问题时一眼能看出是哪次改动导致的

**改完自查：** 双击打开 `prototype/index.html`，看首页能不能正常列出 4 条线路；点进改过的那条，**核对项目数**（C1 应为 16 项、C2 应为 15 项）。数字不对就是改漏或改重了。

## ⚠️ 数据核实状态

**数据是可追溯的，不是编出来的。** 每个节点带 `source` 标记，速查页用圆点可视化：

| 标记 | 含义 |
| --- | --- |
| ⚪ `std` | 国家统一必考项（起止固定） |
| 🟢 `pub` | **公开实测攻略已核实**（目前仅 2 号线） |
| 🔵 `map` | 路线图上明确标注 |
| 🟠 `inf` | 依路线结构推导，**待教练校准** |

考核项依据 **《机动车驾驶证申领和使用规定》（公安部令第 162 号）第三十四条**：C1 手动挡 16 项、C2 自动挡 15 项。**考场之间的差别不在于「考几项」，而在于这些项排成什么顺序、在哪个路段做。**

**目前 2 号线是唯一有公开实测全程记录的线路**（16 步完整可查）；其余线路中标记 🟠 的「路口右转弯 / 路口左转弯 / 通过人行横道线」三项位置为推导，**需教练确认后再定稿**。
